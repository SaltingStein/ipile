# Business and product requirements

This folder holds the project's **BRD** (business requirements) and **PRD** (product requirements). They sit at the top of the SDGP hierarchy:

BRD → PRD → Solution document → Feature spec → ADR → Implementation → Testing → Deployment

**If you started a project from Ìpìlẹ̀:** add `brd.md` and `prd.md` for your product here before writing feature specs. Agents working in this repository will remind you if they are missing.

**For Ìpìlẹ̀ itself:** the boilerplate has no BRD or PRD of its own. Its purpose and scope are described in the [README](../README.md) and the [developer guide](../project-docs/developer-guide.md), and its architecture in [`docs/solution-doc-architecture.md`](../docs/solution-doc-architecture.md). Feature specs for changes to Ìpìlẹ̀ trace to those documents; this is recorded in [`docs/deviations/DEV-20261102-001-hardening-specs-in-implementation-pr.md`](../docs/deviations/DEV-20261102-001-hardening-specs-in-implementation-pr.md).
