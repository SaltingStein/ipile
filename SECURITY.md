# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately, not in a public issue or pull request.

Use GitHub's **[Report a vulnerability](https://github.com/SaltingStein/ipile/security/advisories/new)** form (the Security tab of this repository). Include:

- what the vulnerability is and what an attacker could do with it
- the steps or a proof of concept to reproduce it
- the affected version or commit

We aim to acknowledge reports within three working days and will keep you updated until a fix is released. Once it is fixed, we'll credit you in the advisory unless you prefer to stay anonymous.

## Supported versions

Security fixes are made on the latest release on `main`.
