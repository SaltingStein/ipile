An API token lets a script, integration or other tool use your account through the API without your password. Open **API tokens** from the **Developers** section of the menu.

## Create a token

1. Enter a name you will recognise later, for example "Reporting script".
2. Choose how long it should last, if you are offered a choice.
3. Choose **Create token**.

**Copy the token straight away.** For your security it is shown only once. If you lose it, revoke it and create a new one.

## Expiry

Tokens can expire after a set time, and a token that is not used for a while may stop working. The page tells you the limits that apply. When a token stops working, create a new one.

## Your tokens

The list shows every app and script that can use your account, including signed-in mobile devices, with when each was created, last used and when it expires.

## Revoke a token

Choose **Revoke** next to a token to stop it working immediately. Do this for anything you no longer use or do not recognise.
