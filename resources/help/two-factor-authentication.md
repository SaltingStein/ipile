---
title: Two-factor authentication
summary: Protect your account with a code from an authenticator app.
order: 20
---

Two-factor authentication asks for a short code from your phone each time you sign in, so someone who learns your password still cannot get in.

## Turn it on

1. Open **Account security** from the menu. You may be asked to confirm your password first.
2. Under **Two-factor authentication**, choose to turn it on.
3. Scan the QR code with an authenticator app such as Google Authenticator or Authy.
4. Enter the code from your app and choose **Confirm**.

Some roles must use two-factor authentication. If yours does, you are asked to set it up before you can use the app.

## Recovery codes

When two-factor authentication is on, you get a set of **recovery codes**. Each code works once, in place of a code from your app. Keep them somewhere safe, such as a password manager. You can create a fresh set from **Account security** at any time; the old codes then stop working.

## Signing in

After your password, enter the code from your app. Lost your phone? Choose to use a recovery code instead.

## Trusted devices

At sign-in you may see **Trust this device**. Choosing it skips the code on that device for a while. Only use it on a private device. You can remove all trusted devices from **Account security**.

## Turn it off

Open **Account security** and choose to turn two-factor authentication off. Your account is then protected by your password alone.
