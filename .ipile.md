## Context

This is a Laravel 13 + Inertia React application built on Ìpìlẹ̀. Agent and developer conventions are in `AGENTS.md` and `project-docs/developer-guide.md`.

## Flag as critical

- An admin page or sensitive route without a permission check (`permission:` middleware or a policy).
- Money handled as a float: `(float)`, `round()`, `* 100` or `/ 100` on an amount, or a new decimal money column instead of an integer `*_minor` column converted through `App\Support\Money`.
- A hard delete (`forceDelete()`, `DB::table(...)->delete()`) of a record that uses `SoftDeletesWithRetention`, or a purge of `payments`.
- A secret, token, password or personal value written to a log, an audit entry, an API response or an Inertia prop.
- New personal data stored about a user that is not included in `PersonalDataExport` or not removed or anonymised by `AccountDeletion`.
- A payment webhook or callback processed without verifying its signature or matching the amount against the ledger.

## Flag as warnings

- A new model holding data an admin must account for without the `Auditable` trait, or with personal fields missing from `$auditRedacted`.
- Rate limiting with `throttle:N,M` instead of a named limiter in `App\Services\RateLimits`.
- An operator setting read from `.env` or hard-coded instead of the `Setting` model.
- A migration without a working `down()` method.
- New behaviour without a feature test.
- A change that should have an ADR (money, personal data, security boundary, new external dependency, deployment) with no ADR in `docs/adr/`.
